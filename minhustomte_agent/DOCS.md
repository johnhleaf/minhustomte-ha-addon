# Konfiguration

1. Skapa en AUTH-CODE i **MinHustomte HQ → Stugor → Hub / Gateway**.
2. Ange `auth_code` i add-onens konfiguration.
3. Låt `server_url` vara `https://portal.minhustomte.se`.
4. Starta add-onen.

AUTH-CODE används endast vid första parkopplingen. Därefter sparas en unik hub-token lokalt. Om hubben kopplas bort i HQ måste den paras om.
